# PCB Design Practice

A collection of PCB designs created while learning and practicing **PCB design and layout**.

This repository contains boards designed for practice, experimentation, and improving my understanding of the PCB design process.

## About

The purpose of this repository is to document my progress in PCB designing through hands-on practice.

Some boards may be experimental or imperfect, as this repository is primarily focused on **learning and improvement**.

## Tools & Software

The PCBs in this repository may be designed using:

* **KiCad**
* **Altium Designer**

## Learning Goals

Through these projects, I aim to improve my understanding of:

* Schematic design
* Component selection and footprints
* PCB layer management
* Component placement
* Trace routing
* Design Rule Checks (DRC)
* Manufacturing considerations
* PCB documentation
* 3D visualization and board inspection

## Progress

This repository will be updated as I continue learning and designing new boards.

> **Note:** These designs are primarily for learning and practice. Always verify the schematic, PCB layout, footprints, clearances, and design rules before manufacturing or using any board.
